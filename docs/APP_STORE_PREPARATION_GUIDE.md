## 4. Privacy Policy (COPPA Compliant)

### Requirements
- Must be COPPA compliant (kids under 13)
- Must be hosted on a public URL
- Must be accessible from app

### Privacy Policy Template

```markdown
# Privacy Policy for LearnoSphere

**Last Updated**: October 2, 2025

## Introduction
LearnoSphere ("we", "our", "us") is committed to protecting the privacy of children. This app is designed for children ages 5-12 and complies with the Children's Online Privacy Protection Act (COPPA).

## Information We Collect
We collect minimal information:
- **Game Progress**: Levels completed, XP earned, skills unlocked
- **Settings**: Sound preferences, tutorial completion status
- **NO Personal Information**: We do NOT collect names, emails, photos, or any personally identifiable information

## How We Store Data
- All data is stored **locally** on your device
- Data is **encrypted** for security
- Data is **never** transmitted to our servers
- Data is **never** shared with third parties

## Third-Party Services
We use the following third-party services:
- **Firebase Analytics** (optional): Anonymous usage statistics
  - No personal information collected
  - Can be disabled in settings
  - Used only to improve app quality

## Parental Rights
Parents have the right to:
- Review data stored on the device
- Delete all data (via app settings)
- Disable analytics (via app settings)
- Contact us with questions

## Data Deletion
To delete all data:
1. Open app settings
2. Tap "Delete All Data"
3. Confirm deletion

Or uninstall the app to remove all data.

## Changes to This Policy
We may update this policy. Changes will be posted here with a new "Last Updated" date.

## Contact Us
Email: support@learnosphere.app
Website: https://learnosphere.app

## COPPA Compliance
This app is designed for children under 13 and complies with COPPA. We do not knowingly collect personal information from children.
```

## 9. Submission Process

### Google Play Store

1. **Create Developer Account** ($25 one-time fee)
2. **Create App Listing**
   - Upload screenshots
   - Upload feature graphic
   - Write description
   - Set content rating
3. **Upload APK/AAB**
   - Build release version
   - Sign with release key
   - Upload to console
4. **Complete Store Listing**
   - Set pricing (free)
   - Select countries
   - Add privacy policy URL
5. **Submit for Review**
   - Review takes 1-7 days
   - Address any issues
   - Publish when approved

### Apple App Store

1. **Create Developer Account** ($99/year)
2. **Create App in App Store Connect**
   - Set bundle ID
   - Upload screenshots
   - Write description
   - Set age rating
3. **Upload Build via Xcode**
   - Archive app
   - Upload to App Store Connect
   - Wait for processing
4. **Complete App Information**
   - Set pricing (free)
   - Select countries
   - Add privacy policy URL
   - Add support URL
5. **Submit for Review**
   - Review takes 1-3 days
   - Address any issues
   - Publish when approved
