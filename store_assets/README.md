# App Store Assets

This directory contains all assets needed for app store submissions.

## Directory Structure

- `screenshots/` - App screenshots for different screen sizes
- `descriptions/` - App descriptions and metadata
- `icons/` - App icons in various sizes
- `promotional/` - Promotional graphics and banners

## Screenshots Required

### Google Play Store
- Phone: 1080 x 1920 (minimum 2 screenshots, maximum 8)
- 7-inch tablet: 1200 x 1920 (optional)
- 10-inch tablet: 1920 x 1200 (optional)

### Apple App Store
- iPhone 6.7": 1290 x 2796 or 1284 x 2778
- iPhone 6.5": 1242 x 2688 or 1284 x 2778
- iPhone 5.5": 1242 x 2208
- iPad Pro (6th gen) 12.9": 2048 x 2732
- iPad Pro (2nd gen) 12.9": 2048 x 2732

## App Information

**App Name:** StudyPal - AI Learning Companion

**Short Description:** Personalized AI-powered learning with adaptive difficulty and comprehensive subject coverage.

**Category:** Education

**Target Audience:** Students, learners, educational institutions

**Key Features:**
- AI-powered question generation
- Adaptive difficulty system
- Multi-subject support (Math, Science, Computer Science, etc.)
- Progress tracking and analytics
- Gamification with gems and streaks
- Offline capability with online AI enhancement
