# Manual Screenshot Capture Instructions for Google Play Store

## 🎯 Overview
You need to capture **8 high-quality screenshots** for your StudyPal app's Google Play Store submission.

## 📱 Setup Instructions

### Step 1: Browser Setup
1. Open **Chrome** or **Microsoft Edge**
2. Navigate to: `http://localhost:8080`
3. Press **F12** to open Developer Tools
4. Click the **device toggle icon** (📱) in the toolbar
5. Set **custom dimensions**: `1080 x 1920` pixels
6. Set **device pixel ratio**: `1.0`

### Step 2: Screenshot Requirements
- **Resolution**: 1080 x 1920 pixels (portrait)
- **Format**: PNG (preferred) or JPEG
- **File size**: Maximum 8MB per image
- **Quality**: High-resolution, clear and readable text

## 🔧 Capture Process

### Method 1: Browser Screenshot
1. Navigate to the desired screen
2. Right-click anywhere on the page
3. Select **"Save screenshot as..."** or **"Capture screenshot"**
4. Save as PNG format with the specified filename

### Method 2: DevTools Screenshot
1. In DevTools, press **Ctrl+Shift+P** (Windows)
2. Type **"screenshot"**
3. Select **"Capture full size screenshot"**
4. Save with the specified filename

### Method 3: Windows Snipping Tool
1. Press **Windows + Shift + S**
2. Select the mobile viewport area
3. Save as PNG with the specified filename

## 📁 Save Location
Save all screenshots in: `E:\sp\store_assets\screenshots\google_play\`
